# CPRAM Fleet — ระบบบริหารจัดการรถขนส่งควบคุมอุณหภูมิ

เว็บแอประบบจริง (ไม่ใช่ตัวอย่าง) สำหรับบันทึกข้อมูลรถ ประวัติการซ่อม กำหนดการ PM และพนักงานขับรถ
รองรับผู้ใช้งานหลายคนพร้อมกันผ่านระบบล็อกอิน ข้อมูลทุกอย่างเก็บในฐานข้อมูลจริง (Supabase/Postgres)

## สิ่งที่ทำได้
- เพิ่ม / แก้ไข / ลบ ข้อมูลรถแต่ละคัน
- บันทึกประวัติการซ่อมแยกตามทะเบียนรถ แก้ไข/ลบได้
- ระบบแจ้งเตือนวันครบกำหนด PM อัตโนมัติ (คำนวณจากวันที่จริง)
- แดชบอร์ดภาพรวมความพร้อมของรถและค่าใช้จ่ายซ่อมบำรุงรายเดือน
- เพิ่ม / แก้ไข / ลบ ข้อมูลพนักงานขับรถ
- ผู้ใช้ทุกคนที่ล็อกอินเข้าระบบมีสิทธิ์แก้ไขข้อมูลเท่ากัน

## เริ่มต้นใช้งาน
ทำตามขั้นตอนในไฟล์ **SETUP.md** ตั้งแต่ต้นจนจบ (สร้างฐานข้อมูล → อัปโหลดโค้ด → เผยแพร่เว็บ)
ใช้เวลาประมาณ 20-30 นาที ไม่ต้องเขียนโค้ดเพิ่มเลย

## รันทดสอบในเครื่องตัวเอง (สำหรับผู้ที่ถนัดเขียนโค้ด)
```
npm install
cp .env.local.example .env.local   # แล้วใส่ค่า Supabase URL/Key ของคุณ
npm run dev
```
เปิด http://localhost:3000

## โครงสร้างไฟล์
```
pages/            หน้าเว็บ (login, index)
components/       ตัวแอปหลักทั้งหมด (FleetApp.js)
lib/              การเชื่อมต่อ Supabase
supabase/         ไฟล์ SQL สร้างฐานข้อมูล
```
